# Book Market Analytics — Data Science 500

A PyCharm-ready, reproducible project that scrapes the Books to Scrape practice catalogue, cleans the data, explores price and rating patterns, creates visualisations, and evaluates a linear regression baseline.

## Open and run in PyCharm

1. Extract the ZIP file.
2. Open PyCharm → **Open** → select the `Data_Science_500_Book_Market_Analytics` folder.
3. Use Python 3.10 or newer. In **Settings → Project → Python Interpreter**, create a new virtual environment.
4. Open PyCharm's Terminal and run:

   ```bash
   python -m pip install -r requirements.txt
   python -m src.scraper
   python -m src.analysis
   ```

5. Open `notebooks/book_market_analytics.ipynb` and select the same virtual environment as the notebook kernel. Run the cells from top to bottom.

The scraper follows the catalogue's “next” page link and should collect the whole catalogue (normally 1,000 books). Please run it while connected to the internet. The output dataset is created by the scraper; no invented book data is bundled as if it were real.

## Deliverables generated

- `data/raw/books_raw.csv` — fields scraped from the site
- `data/processed/books_clean.csv` — cleaned dataset
- `outputs/figures/` — price distribution, price by rating, and stock charts (plus category chart if category data is available)
- `reports/model_metrics.json` — MAE, RMSE and R² from a held-out test set
- `notebooks/book_market_analytics.ipynb` — full documented workflow

## Method notes

- The target is book price in GBP.
- Rating words are mapped to numbers One=1 through Five=5.
- Records without a usable title, price, or rating are excluded from modelling; duplicates and negative prices are removed.
- The baseline linear regression uses rating, stock status, and stock quantity. These are available listing features, but they may not explain price well. The evaluation metrics should be interpreted honestly and not presented as proof that ratings cause prices.
- `category` is retained as a field, but the catalogue-wide listing page does not expose category for each book. It remains blank unless you extend the scraper to visit product pages or category pages.
